核心模型 · PDF 11–35 頁

創世記 1:2 與太古審判模型

聚焦 tohu va-bohu、約伯記、詩篇、彼得後書、以賽亞書、以西結書與約翰福音，形成「原初創造 → 叛逆 → 審判 → 荒廢空虛 → 恢復」的研究模型。

  • 原文模組：hayetah、tohu va-bohu 的語義與其他經文用例。
  • 經文鏈：伯 38、詩 104、彼後 3、賽 14、結 28、約 12/14/16 等。
  • 一致性檢驗：模型可形成連貫敘事，但「撒但敗壞地球」「創 1:2 必然是審判」仍屬推論層次。
  • 延伸討論：拉哈伯、大型水中生物、巨大生物消失與科學災變敘事的現象比對。

生命科學 · PDF 36–46 頁

生命起源、DNA 程式與第三日恢復

從創世記第三日的植物、種子與「各從其類」出發，討論 DNA、mRNA、啟動子、表觀遺傳、ZGA，以及星際前生物分子的研究方向。

  • 生命啟動：母源 mRNA、表觀遺傳與 ZGA 被整理成「啟動程式」問題。
  • 材料來源：區分胺基酸、核苷酸、肽等前生物分子與「完整 DNA」兩種不同層次。
  • 三軸對照：創 1:9–13 × 希伯來文語法 × 科學模型。
  • 研究假設：以「恢復」視角理解既有生命材料與生命程式的重新啟動／調整。

人類出現的環境、人種與證據

整理智人出現的時間框架、古人類、人類活動環境，以及基因、石器、骨器、火、住屋、藝術與生活器物等證據類型。

  • 環境面：氣候、草原、河谷湖泊與大型動物群的變化。
  • 人種面：直立人、海德堡人、尼安德塔人、丹尼索瓦人與智人。
  • 證據面：化石年代、古 DNA、工具、生活器皿與象徵行為。

整合 · PDF 53–62 頁

地的恢復經文與完整時間軸

把耶利米書、以賽亞書、詩篇、約伯記、彼得後書與啟示錄串成恢復主線，最後整理成從創 1:1 到創 1:31、再到啟 21 的時間軸。

  • 恢復經文：荒廢、空虛、黑暗、深淵、水退去、地面更新等主題。
  • 時間軸：原初創造 → 墮落／審判 → 創 1:2 → 六日恢復 → 人類 → 新天新地。
  • 模組化總結：審判模組、恢復模組、人類模組、終極恢復模組。
  • 整份研究在此收束成一條可繼續擴充的經文研究主線。
